# Extension Icons

This directory should contain the following icon files:

- `icon16.png` - 16x16 pixels (browser toolbar)
- `icon48.png` - 48x48 pixels (extensions page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Creating Icons

### Option 1: Use an Online Generator
Visit [Icon Generator](https://www.iconsgenerator.com/) or similar tools to create icons from an image or emoji.

### Option 2: Design Your Own
Use tools like:
- Figma
- Adobe Illustrator
- Inkscape (free)
- Canva

### Option 3: Quick SVG Template

Use the provided `icon-template.svg` as a starting point. You can:
1. Edit it in a vector graphics editor
2. Export at different sizes (16px, 48px, 128px)
3. Convert to PNG format

### Recommended Design

For this extension, consider:
- **Symbol**: Lightning bolt (⚡), thread icon, or extraction symbol
- **Colors**: Amber/ochre (#f59e0b) on dark background (#1a1714)
- **Style**: Modern, geometric, clean
- **Contrast**: High contrast for visibility

### Quick Placeholder

Until you create custom icons, you can use emoji as temporary placeholders:
1. Take a screenshot of a large ⚡ emoji
2. Crop and resize to 128x128, 48x48, and 16x16
3. Save as PNG files with appropriate names

The extension will still function without icons, but Chrome may show a default placeholder.
